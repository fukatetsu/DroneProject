# 染地児童館操作方法

演目は3つに分かれています。
この演目を順番にターミナルに入力していってください。
入力後は特別な操作はいりません。
最後まで実行されたらEnterキーの待機待ちとなります。
実行されてから離陸までにわざとラグを入れている箇所もあります。

## 1つ目の演目

離陸→上下移動→着陸→離陸→フープ追従→着陸

python src/main.py --scenario src/scenarios/someji_start.json

## 2つ目の演目

離陸→ドローンが自由に移動→着陸

python src/main.py --scenario src/scenarios/someji_mid.json

## 3つ目の演目

離陸→ドローンが弧を描く→フープ追従→着陸
python src/main.py --scenario src/scenarios/someji_last.json

# コマンド

実行中にターミナルに入力してEnterを押すことで発行されます

- p, pp ドローンの停止 Pauseキーです
- land ドローンの着陸 Pauseの後に実行してください

# ドローンとの接続

ドローンとはWi-Fiで接続しています。
ドローンの起動・再起動時にはTello から始まるアクセスポイントにPCからアクセスしてください。

# フープとの接続

GeoMotionを用いて接続しています。
アプリケーションで接続が確認できれば、特に特別な操作は必要ありません。


本作品は、人とドローンとの関わりを通して、ドローンという存在を問い直すことをテーマとしたパフォーマンスである。

ドローンは軍事技術として発展し、現在も世界各地の戦場で運用されている。その歴史的背景から、脅威や危険の象徴として捉えられることも多い。一方で、近年では映像撮影や物流、災害調査、ドローンショーなど幅広い分野で活用され、人々の生活や文化を支える技術としての側面も持つ。しかし、実際に間近で飛行するドローンは、けたたましい飛行音や人間とは異なる無機質な動きから、恐怖や不気味さを抱かせることがある。

ドローンは本作品の中で、人とともに表現を創り上げる「パートナー」として描かれる。人とドローンが互いに影響を与えながら演技を紡ぐ姿を通して、軍事技術としての側面だけではないドローンの可能性を提示し、観客がドローンに対する先入観を見つめ直し、その本質について考えるきっかけとなることを目指す。また、人との関わりの中でドローンを描くことで、単なる機械や道具としてではなく、人との関係性の中でその存在を捉え直す視点を提示する。

本作品では、フープとフープに搭載した慣性計測装置（IMU）、ドローン、自律飛行システム、映像投影を組み合わせることで、人とドローンがパートナーとして互いに影響を与え合うパフォーマンスを実現している。

フープの姿勢情報をリアルタイムに取得し、ドローンの飛行へ反映することで、演者の身体表現とドローンの動きが呼応するインタラクションを実現する。フープの姿勢や回転に応じてドローンが旋回や移動を行うことで、人の動きに合わせて応答するパートナーとしての振る舞いを表現している。一方で、すべての動きを演者が制御するのではなく、シーンに応じて自律飛行とリアルタイムインタラクションを組み合わせることで、ドローン自身の存在感を活かした多様な演出を可能としている。

また、フープにはスクリーンを設け、局所的な映像投影を行う。身体の動きと映像を一体化させることで、フープを単なる道具ではなく表現媒体として機能させ、人・ドローン・映像が一体となった空間演出を実現している。

パフォーマンスでは、人がドローンを一方的に操作するのではなく、ドローンの動きに応じて演者も身体表現を変化させながら演技を展開する。両者が互いの動きに影響を与えながら一つの表現を創り上げることで、人とドローンがパートナーとして共演する新たな関係性を提示する。


項目	要求事項
舞台	幅4間（約7.2 m）程度。奥行きの指定なし。
天井高	指定なし（2 m以上が望ましい）
床	指定なし
照明	演技中に明るさを変更可能であること（特殊照明は不要）
映像	プロジェクター1台（スクリーン不要。フープへ投影）
音響	ステレオ再生対応
観客	ドローン飛行時の安全を確保するため、観客との十分な離隔距離を確保することが望ましい。
空調	パフォーマンス中は、ドローンの飛行への影響を避けるため空調を停止することが望ましい。
