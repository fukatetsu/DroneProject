# 顔追従の調整ガイド

このガイドは、顔追従のカメラ内目標位置や応答速度を調整する人向けの手引きです。実機で安全が確認された設定値を示すものではありません。まずMockで動作を確認し、実機では十分な空間・補助者・即時着陸手段を確保してください。

## まず調整する場所

- 顔を画面内のどこに合わせるか: [`FaceFollowShow`の`horizontal_target_ratio`と`vertical_target_ratio`](../../../src/shows/interaction/face_follow_show.py)
- 顔のずれに対する旋回・上下の反応の強さ: 同ファイルの`yaw_gain`と`gain`
- 小さなずれを無視する範囲: 同ファイルの`deadband`
- RC指令の最大値: `FaceFollowShow`の`max_speed`。実機起動時は[`main.py`](../../../src/main.py)の`face_follow_max_speed=40 if args.real else None`が実機用の値を上書きします。

CLI実行時、目標比率・ゲイン・デッドバンドは[`face_follow_show.py`](../../../src/shows/interaction/face_follow_show.py)の`__init__`既定値を変更します。`FaceFollowShow(...)`を直接生成する箇所ではキーワード引数で上書きできます。起動時にまとめて調整する設定ファイルは現状ありません。

## 設定値一覧

| 設定 | 現在の既定値 | 意味・使い方 |
|---|---:|---|
| `horizontal_target_ratio` | `0.5` | 顔を合わせる水平位置。画像幅に対する割合で、0.5は中央。左右のカメラ取付ずれや、中央以外を目標にしたい場合に調整する。 |
| `vertical_target_ratio` | `0.5` | 顔を合わせる垂直位置。画像高さに対する割合で、0.5は中央。0.5より小さい値は画面上側、大きい値は下側の目標になる。 |
| `yaw_gain` | `30` | 水平方向のずれに対するYaw指令の強さ。大きくすると同じずれでより大きな旋回指令になる。 |
| `gain` | `50` | 垂直方向のずれに対する上下指令の強さ。大きくすると同じずれで上下指令が大きくなる。 |
| `deadband` | `0.08` | 正規化誤差がこの値以下なら該当軸の指令を0にする範囲。大きくすると小さな揺れを抑えられるが、中央付近に残るずれは大きくなる。 |
| `max_speed` | `50` | 各軸へ出すRC指令の絶対値上限（許容範囲1〜100）。ゲインを上げてもこの値を超えない。 |
| `poll_interval` | `0.1`秒 | 顔解析・制御ループの周期。短くすると更新頻度が上がるが、処理負荷も増える。 |
| `target_switch_interval` | `15`秒 | 複数の顔が候補にあるとき、追従対象を切り替えるまでの時間。 |
| `target_lost_grace` | `1.0`秒 | 選択中の顔が一時的に見えなくなった場合に、対象を維持する猶予時間。猶予中はRC指令を停止する。 |
| `frame_failure_timeout` | `2.0`秒 | 映像入力が復旧しない場合にShowを異常終了するまでの時間。入力異常中はRC指令を停止する。 |

目標位置の比率は`0 < ratio < 1`で指定します。例えば`horizontal_target_ratio=0.55`は、画面幅の55%位置を水平の目標とします。映像上には設定した水平・垂直の目標線が表示されます。

## ずれ方を見て調整する

1. 表示映像で顔中心と目標線の交点を比較します。交点が顔を置きたい位置です。
2. 顔が安定しても交点から外れて見える場合は、まず`horizontal_target_ratio`または`vertical_target_ratio`を調整します。これは「目標位置」の調整です。
3. 目標線から大きく外れた顔への反応が遅い場合は、対応する`yaw_gain`または`gain`を少し上げます。振動・行き過ぎが増えた場合は下げます。これは「反応の強さ」の調整です。
4. 目標付近で細かく指令が切り替わる場合は`deadband`を少し上げます。残るずれが許容できないほど増えた場合は戻します。
5. 調整は一度に一つの値だけ変更し、同じカメラ位置・照明・距離で比較します。指令が`max_speed`で頭打ちになる場合、ゲインをさらに上げても反応は速くならず、上限設定の見直しが必要です。

カメラや機体の向きによって、画面内の誤差と実際の移動の見え方は変わります。比率を変えたときに機体がどちらへ動くかは、映像上の目標線と小さな指令で確認してください。特に上下軸の符号や機体高度は、実機で推測だけで変更しないでください。

## 実機モードのRC上限

`FaceFollowShow.max_speed`の既定値は50ですが、`--real`で起動すると[`main.py`](../../../src/main.py)が`face_follow_max_speed=40`を渡し、実機向け上限を40にします。実機上限を調整する場合は、`main.py`の`face_follow_max_speed=40 if args.real else None`にある`40`を変更します。Mockではこの上書きは行わず、Showの既定値が使われます。

`max_speed`はTelloへのRC指令値（軸ごとの-100〜100）の絶対値上限であり、実際の速度を物理単位で直接指定する値ではありません。上限を上げると応答が急になり、衝突や姿勢変化のリスクも増します。安全確認なしに実機の上限を上げないでください。

## 運用上の注意

- `FaceFollowShow`は離陸・着陸を担当しません。シナリオ側で操作・遷移を確認してください。
- 現行の実機シナリオは30秒飛行後に自動着陸します。飛行中に異常があれば操作者が直ちに着陸できる状態を維持してください。
- 顔が検出されない場合や映像入力異常時は、追従指令を継続せずRC全軸を0にします。
- トラックIDは顔の認証情報ではなく、一時的な追跡IDです。複数人の場面では意図しない対象への切替に注意してください。
- `gain`、`yaw_gain`、`max_speed`は画面上の指令を調整します。カメラ取付の偏りを直したい場合は、まず目標比率を調整してください。
