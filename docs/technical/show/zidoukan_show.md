# 染地児童館での演目

ドローンの離陸に合わせてフープを上にあげる
ドローンが身体に近づくと同時にフープをドローンに近づける

ドローンが回転する
フープは回転に合わせて回転させる

ドローンに上下運動が加わる
フープも上下する

ドローンが静止する
ドローンを手のひらに着陸させて回転の向きを整える

ドローンが身体の周りをゆっくりと一周まわる

ドローンが静止する
ドローンを手のひらに着陸させて回転の向きを整える

アイソレーションパート
ドローンがカクカクと動く

インタラクションパート
ドローンがフープの向きに合わせて加速度を変える
時折向きや高さを変える

インタラクションパート2
ドローンがフープの向きに合わせて向きを変える
進む速度を時折変える

だんだんとドローンが下っていく
