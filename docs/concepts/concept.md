# コンセプト
　本作品は、フープを持った人とドローンの動きによるインタラクションで、ドローンという存在の意味を新しく描き出すことをテーマとしたパフォーマンスである。　
　2026年（現在）、ドローンは軍事技術として発展し、戦場で利用されている。脅威や危険の象徴として捉えられることも多い。実際に間近で飛行するドローンは、けたたましい飛行音や無機質な動きから、恐怖や不気味さを抱かせることがある。一方で、ドローンは、映像撮影や物流、災害調査、ドローンショーなど幅広い分野で活用され、社会生活を支え、新しい文化を担う技術としての側面も持つ。
　ドローンは本作品の中で、人とともに表現を創り上げる「パートナー」として描かれる。人とドローンが互いに影響を与えながら演技を紡ぐ姿を通して、軍事技術とは異なる友好的なドローンの姿を提示し、ドローン利用の、文化的、芸術的、教育的な意義について考えるきっかけとなることを目指す。また、ドローンと人間の身体がインタラクティブに躍動する新たなパフォーミングアートの在り方を探求する。
