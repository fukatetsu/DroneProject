# 作品説明

　本作品は、IMUモーションセンサーを搭載したフープ（円形の輪状の道具）、小型ドローン、PC1台（BLE受信プログラムとドローン飛行システムを搭載）を用い、フープを動かすパフォーマーの動きとドローンの飛行が、互いに影響を与え合いながら進行するパフォーミングアートである。フープの姿勢情報をリアルタイムに取得し、ドローンの飛行へ反映することにより、演者の身体表現とドローンの動きが呼応するインタラクションを実現している。
　システムでは、フープの姿勢や回転に応じて、ドローンが旋回や移動を行う指示を出す。その結果、フープを持つ人の動きに応じて、ドローンは、3次元的な動きによって応答する。それを見ながら演者は、次の動きを即興的に決定していく。ドローンのすべての動きをリアルタイムインタラクションによって決定するのではなく、ドローンが自律飛行するシーンも演出に加え、ドローンとパフォーマーが分離され、それぞれの存在感を感じられる場面も設けた。
　パフォーマンスでは、人がドローンを一方的に操作するのではなく、ドローンの動きに応じて演者も身体表現を変化させながら演技を展開する。両者が互いの動きに影響を与えながら一つの表現を創り上げることで、人とドローンがパートナーとして共演する、新たなパフォーミングアートを構想した。
